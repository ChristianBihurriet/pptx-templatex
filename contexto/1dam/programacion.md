# Programación — conocimientos previos de 1DAM

Archivo editable por el profesor. Perfil inicial de ejemplo, no currículo oficial.
Confirma esta lista antes de generar una clase.

## Conocimientos de partida para el ejemplo de herencia

- Variables, tipos básicos, cadenas y operadores aritméticos.
- Condicionales, bucles y métodos sencillos.
- Estructura de `public static void main(String[] args)` y salida con `System.out.println`.
- Declaración básica de una clase, creación de objetos con `new` y llamada a métodos.
- Guardar `Main.java`, compilar con `javac Main.java` y ejecutar con `java Main`.

## Aún no se deben dar por conocidos

Herencia, polimorfismo, interfaces, clases abstractas, genéricos y composición.
Los modificadores de acceso requieren explicación al introducirlos.
